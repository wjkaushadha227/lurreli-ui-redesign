# 🛍️ Lurreli Online Shopping Store – UI/UX Redesign

## 📌 Project Overview
This project focuses on analyzing and improving the user experience of an existing e-commerce platform.

The original website had several usability issues related to navigation, visual design, feedback, and accessibility.  
A redesigned interface was created using user-centered design principles to enhance usability and overall experience.



## 🎯 Objectives
- Improve navigation and information structure  
- Enhance visual hierarchy and consistency  
- Provide better feedback and error handling  
- Improve accessibility and readability  
- Create a modern and user-friendly interface  



## 🔍 Methodology
The evaluation was conducted using:

- Heuristic Evaluation (Nielsen’s Usability Heuristics)  
- Simulated User Testing  
- Simulated User Survey  



## ⚠️ Key Issues Identified
- Unclear navigation structure  
- Inconsistent UI elements  
- Poor visual hierarchy  
- Weak feedback and error handling  
- Confusing size & color selection  
- Limited accessibility  



## 💡 Redesign Improvements
- Clean and structured layouts  
- Consistent typography and colors  
- Improved navigation and filtering  
- Clear feedback messages and validation  
- Better product display and selection UI  
- Enhanced forms (Login / Signup / Contact)  



## 🎨 Design Highlights
- Modern and minimal UI  
- Improved user flow and interaction  
- Better readability and spacing  
- Strong visual identity (colors & typography)
